# Session shapes — no-plan default, extra practice, pausing

Read when the situation arises (session start without a schedule; agenda done
early; the student pauses).

## No schedule: the after-lecture recap session

This is the mid-semester default — the student imported a lecture a few days ago
and wants to solidify it so exam prep goes faster later. Shape:

1. **Core: the newest digest's topics** (status `new` or recently imported) — this
   is the material to solidify while it's fresh.
2. **Plus 1–2 older topics due a spaced recap.** Pick by: status (`weak` first),
   Last date (longest ago first), and **thematic ties to the new material** —
   recapping the older topic the new one builds on doubles as scaffolding for it.
   The newest digest's **§Connections** section is the first place to look: a
   "builds on digest-03 (T12)" line is a recap candidate, and a "resolves digest-05
   open question" line is a teaching moment worth one sentence when the topic comes
   up ("this is the gap lecture 5 left open"). Say why you picked them ("T03 feeds
   directly into this").
3. Same session structure as always: warm-up → agenda → modes per topic →
   boundaries → session end. Sizing: these sessions are typically shorter than
   exam-prep sessions; a lecture's worth plus recap in ~30–45 min is normal —
   don't inflate the agenda to fill an hour.

Recap evidence is evidence: if an older topic turns out shaky, its status drops,
dated today — that's the system working, not a problem.

## Extra practice — agenda done, time remains

"Keep going", "give me more" after the day's slice is cleared isn't new-topic
territory — there's no fresh slice to open. Spend the spare time making what's
*already* studied stick. Draw on a **mix**, in **no fixed order** — pick what fits
the moment and vary:

- **Re-recall today's material** — active-recall passes over what this session
  covered, so it consolidates instead of fading by tomorrow.
- **Go deeper where coverage was shallow** — the harder sub-cases, the edge
  conditions, the *why* behind a formula only stated.
- **Reach back to earlier days (spaced recall)** — pull prior topics up before
  they decay; re-read their digests first so questions come from the material,
  not a fading memory of it.
- **Real exam questions** — lecturer examples and exam-brief archetypes as actual
  practice; layers onto any of the above once a topic is reasonably solid.

All usual rules stay in force: announce modes, propose-don't-impose at
boundaries, and extra practice is still evidence — a shaky earlier-day topic gets
its status updated like anything else.

## Pausing vs finishing

- **Finishing** — agenda done or the student is wrapping up studying for now: run
  the full session-end routine.
- **Pausing** — "take a break", "let's stop for now", "I need to pause": read it
  as *wrap what we've done; I'll start a fresh session later today for the rest.*
  Not "done for the day", not "I'm behind."

When the student pauses:

1. **Stop gracefully where you are.** Finish the current question if mid-way, but
   don't cram or speed-run the remaining agenda "to get through it" — the point of
   pausing is to stop.
2. **Run the session-end update for what was actually covered.** Covered topics
   get status from what was demonstrated, dated today. Unreached topics stay
   exactly as they were — don't advance, don't mark reviewed, don't guess. Still
   deliver the file with the re-upload reminder — it matters *more* here, since
   the next sitting is later today.
3. **Don't touch the schedule.** A pause isn't falling behind — today's slice is
   just split across two sittings. Leave the Schedule section alone unless the
   covered part genuinely changed priorities, and even then keep the remaining
   topics on today.
4. **Hand off cleanly:** close with one line of exactly what's left for later
   today — remaining items with estimates — so the next session picks up without
   re-deriving where things stood. *"Paused here. Still to do today: [topic] ~15m
   · [topic] ~20m. Restart whenever — I'll pick up from [next topic]."*
